Miscarriage Symbol Test

Test 1: Basic Miscarriage Symbol Comparison

This test shows the relationship between Unknown (full diamond) and Miscarriage (upper triangle, half-size).

Expected: Miscarriage is an upward-pointing triangle that is approximately half the size of the unknown diamond.

Test 2: Miscarriage in Pedigree Context

This test shows how miscarriages should appear in a simple family structure.

Expected: The miscarriage appears as a small upward-pointing triangle connected to the parents via pedigree lines, just like other children.

Test 3: Miscarriage with Clinical Data

If a miscarriage has clinical data (unlikely but possible), stroke-width should be 3.

Implementation Detail: The draw_miscarriage() function checks has_clinical_entries() and sets stroke-width to 3 if diseases or procedures are present.

Data Structure Test

A miscarriage record should have life_status == "Miscarriage":

{
  "name": "M Placid Wolf",
  "born": "UN/UN/UNKN",
  "deceased": "UN/UN/UNKN",
  "father": "05643-02-001",
  "mother": "05643-02-002",
  "life_status": "Miscarriage",
  "demographics": {
    "gender": "Unknown"
  }
}
Note: The life_status property is checked BEFORE gender in the draw_person() function.
